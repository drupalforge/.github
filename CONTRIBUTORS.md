## Add or update your row

Anyone who contributes to Drupal Forge can be listed. Listing is optional, and
it doesn't grant access to anything.

[Open a contributor directory issue](https://github.com/drupalforge/.github/issues/new?template=contributor-directory.yml)
with your accounts. A maintainer assigns the issue to your GitHub account and
approves it, then a pull request with your row is opened automatically. To
change your row later, open another issue.

To be removed, ask in
[#drupalforge](https://drupal.slack.com/archives/C077WUMH7P1) on Drupal Slack
or open a pull request that deletes your row.

## For maintainers

1. Check that the accounts in the issue belong to the person being listed.
2. Assign the issue to that person's GitHub account. GitHub lets you assign
   the issue author, anyone who has commented, or anyone with repository
   access.
3. Add the **add to directory** label. The workflow checks that each account
   exists, then opens a pull request that closes the issue. If a check fails,
   it comments with what to fix and removes the label.
4. Review and merge the pull request.
