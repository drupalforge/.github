## Add or update your row

Anyone who contributes to Drupal Forge can be listed. Listing is optional, and
it doesn't grant access to anything.

[Open a contributor request issue](https://github.com/drupalforge/.github/issues/new?template=contributor-directory.yml)
and choose a directory listing, with or without a membership request. A
maintainer assigns the issue to your GitHub account and approves it, then a
pull request with your row is opened automatically if a change is needed. To
change your row later, open another issue.

To be removed, ask in
[#drupalforge](https://drupal.slack.com/archives/C077WUMH7P1) on Drupal Slack
or open a pull request that deletes your row.

## Request GitHub organization membership

Use the [same form](https://github.com/drupalforge/.github/issues/new?template=contributor-directory.yml)
to request membership from the GitHub account you want invited. You can request
membership without a directory listing, or request both. The issue and its
contents are public.

An organization owner reviews your request and, if approved, sends an
invitation. You must accept the invitation to join; submitting the issue does
not grant access. Drupal Forge currently requires two-factor authentication
on GitHub.

## For maintainers

1. If membership is requested, notify an organization owner. The owner
   reviews the request and, if approved, invites the issue author.
2. If a directory listing is requested:
   - Add the **contributor directory** label and check that the accounts belong
     to the person being listed.
   - Assign the issue to that person's GitHub account. GitHub lets you assign
     the issue author, anyone who has commented, or anyone with repository
     access.
   - Add the **add to directory** label. The workflow checks that each account
     exists, then opens a pull request if a change is needed. If a check fails,
     it comments with what to fix and removes the label.
   - Review and merge the pull request, if one was opened. If the issue changes
     after the pull request is opened, remove and reapply **add to directory**
     to update it. Directory-only issues close automatically.
3. For membership-only or combined requests, close the issue manually after all
   requested actions are handled.
