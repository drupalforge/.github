[Drupal Forge](https://www.drupalforge.org/) is a volunteer-driven model
marketplace for ready-made Drupal sites that is designed to sustain open
contribution and collaboration.

- [Website](https://www.drupalforge.org/): browse site templates and launch a
  free demo in seconds.
- [Project page](https://www.drupal.org/project/drupalforge): learn how Drupal
  Forge works and why.
- [Road map](https://www.drupal.org/docs/getting-started/sustainability/sustainable-contribution/drupal-forge/drupal-forge-road-map):
  explore planned work.
- [Documentation](https://drupalforge.github.io/.github/): shared instructions
  for visitors and organization members.

## Build a site template

Sell ready-made Drupal sites and earn recurring revenue.

Follow the [template setup guide](https://drupalforge.github.io/.github/template-setup.html)
for repository setup, quick start images, DevPanel configuration, and your
Drupal Forge template page. See [vendor information](https://drupalforge.github.io/.github/community.html#sell-site-templates)
to sell sites through Drupal Forge.
