# Drupal Forge press kit

Resources for journalists, event organizers, bloggers, and partners writing
about Drupal Forge.

## About Drupal Forge

Drupal Forge is a volunteer-driven model marketplace for ready-made Drupal sites
that is designed to sustain open contribution and collaboration. For short and
long descriptions, see [boilerplate](boilerplate.md).

## Key facts

| | |
| --- | --- |
| Name | Drupal Forge (machine name: `drupalforge`) |
| What it is | Marketplace and demo platform for ready-made Drupal sites |
| Who runs it | Volunteers from the Drupal community |
| Funding | Donors through [Open Collective](https://opencollective.com/drupalforge) |
| Fiscal host | OPS Association |
| Website | <https://www.drupalforge.org/> |
| Project page | <https://www.drupal.org/project/drupalforge> |

## What makes it different

- **Instant demos.** Visitors launch a disposable demo of a site template in
  seconds, with no installation.
- **Ownership.** Site owners get hosted convenience and still own their sites.
- **Contribution built in.** Partners are asked to share subscription revenue
  with the Drupal Association and the Drupal projects their products rely on.
- **A cloud development environment.** Every demo includes one, and it also
  gives contributors a cloud environment for working on Drupal.
