# Drupal Forge brand guidelines

Use these guidelines when you write about Drupal Forge or use its logo. For
ready-to-use descriptions, see [boilerplate](boilerplate.md). For media
resources, see the [press kit](press-kit.md).

## Name

- Write **Drupal Forge**: two words, both capitalized.
- Don't write `DrupalForge`, `Drupalforge`, `Drupal-Forge`, or `DF` in public
  copy.
- Use lowercase `drupalforge` only in machine names such as URLs, repository and
  package names, hashtags, and handles.

## Logo

The logo combines the Drupal drop with crossed forge hammers. The approved
artwork is the **Final Logos** frame in the
[Figma source](https://www.figma.com/design/g4xiifOjNmy1IVQq5AbP0O/Logos?node-id=1-3896).
Use the supplied SVG files, which are exported from that frame, without
modification.

| Variant | File | Use it for |
| --- | --- | --- |
| Horizontal | [`drupalforge-horizontal.svg`](logo/drupalforge-horizontal.svg) | Headers, footers, and other wide spaces |
| Vertical, stacked text | [`drupalforge-vertical-stacked-text.svg`](logo/drupalforge-vertical-stacked-text.svg) | Square spaces such as avatars, social cards, and slides |
| Vertical, one-line text | [`drupalforge-vertical-one-line-text.svg`](logo/drupalforge-vertical-one-line-text.svg) | Tall or medium spaces where stacked text would be too narrow |
| Mark only | [`drupalforge-mark.svg`](logo/drupalforge-mark.svg) | Favicons, small icons, and places where the name appears nearby |

The Final Logos frame also contains lockups that aren't exported here yet: a
"FORGE"-only version of the vertical and horizontal lockups, a horizontal
lockup with the text to the left of the mark, and a circular badge with
"DRUPAL" and "FORGE" set around the mark inside a blue ring. Ask the maintainers
for an export before you use any of these.

### Backgrounds

Every lockup in the final set has a near-black wordmark on white. The set has no
reversed (light-on-dark) or single-color version. Place the logo on white or a
light, plain background. On dark or busy backgrounds, put it on a white panel.

### Clear space and minimum size

The Figma source doesn't specify clear space or minimum sizes. Until the
maintainers approve final values, use these provisional rules:

- **Clear space:** keep empty space on every side at least equal to the height
  of the capital letters in the wordmark. For the mark alone, use a quarter of
  the mark's width.
- **Minimum size on screen:**

  | Variant | Minimum |
  | --- | --- |
  | Horizontal | 120 px wide |
  | Vertical, stacked text | 80 px wide |
  | Vertical, one-line text | 120 px wide |
  | Mark only | 24 px tall |

  Below these sizes, the wordmark or the hammer detail becomes hard to read. For
  favicons smaller than 24 px, check that the mark is still recognizable.

### Don't

- Recolor, outline, or add gradients, shadows, or other effects.
- Stretch, squash, rotate, or crop the artwork.
- Rearrange the hammers, drop, or wordmark, or retype the wordmark.
- Use artwork from the Figma frames marked **[OLD] Version 1**,
  **[OLD] Version 2**, or **Graphics**. These are earlier drafts and working
  material, not approved logos.
- Combine the logo with another logo so that they read as one mark.

## Color

These colors are used in the final logo artwork in Figma and its SVG exports.
The Figma file has no separate palette sheet, so the logo colors are the brand
palette.

| Role | Hex | RGB |

| Drop blue, shade | `#00598E` | 0, 89, 142 |
| Drop blue, deep shade | `#004975` | 0, 73, 117 |
| Drop outline navy | `#192849` | 25, 40, 73 |
| Drop highlight | `#93C5E4` | 147, 197, 228 |
| Handle yellow | `#FFDE17` | 255, 222, 23 |
| Handle yellow, shade | `#DBBF00` | 219, 191, 0 |
| Handle yellow, deep shade | `#BD9C00` | 189, 156, 0 |

| Hammer head gray, mid | `#808285` | 128, 130, 133 |

For text and interface elements, use drop blue as the primary accent and
wordmark black for text. Use yellow sparingly for highlights; don't use yellow
text on white because it isn't legible.

## Typography

Figma confirms the all-caps wordmark uses **Montserrat Bold**. The wordmark in
the SVG files is outlined, so you don't need the font to use the logo, and you
shouldn't retype it.

The Figma file doesn't specify a typeface for supporting text. For graphics
such as social cards and slides, Montserrat is a suggested match: use Bold for
headings and Regular or Medium for body text. Montserrat is free under the SIL
Open Font License from
[Google Fonts](https://fonts.google.com/specimen/Montserrat).

## Drupal trademark

The logo includes the Druplicon, which is part of the Drupal trademark. Follow
the [Drupal trademark policy](https://www.drupal.org/about/trademark) when you use
Drupal names and marks.
