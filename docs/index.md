# Drupal Forge documentation

Public instructions for visitors and organization members. Drupal Forge is a
volunteer-driven marketplace for ready-made Drupal sites.

- [Build a site template](template-setup.md): prepare your repository, publish
  a quick start image, and track setup on DevPanel and Drupal Forge.
- [Get involved](community.md): volunteer, find work, ask for help, donate, or
  partner with Drupal Forge.
- [Press and brand](brand.md): approved descriptions, logos, and public
  project materials.

Browse templates and launch demos at [Drupal Forge](https://www.drupalforge.org/).
Learn about the project on [Drupal.org](https://www.drupal.org/project/drupalforge).

## About these docs

The source is maintained in the public
[`.github` repository](https://github.com/drupalforge/.github/tree/main/docs).
Propose corrections through a pull request or ask in
[#drupalforge](https://drupal.slack.com/archives/C077WUMH7P1) on Drupal Slack.
Sections marked **TODO** are incomplete, not full setup instructions.

GitHub Pages builds this site's Markdown with Jekyll from `main` and `/docs`.
Changes to this folder are published automatically after they are pushed.
Keep public instructions here and link to canonical brand assets rather than
duplicating them. Never add member-only or administrator documentation here.

Member access and administrator resources remain in the
[member profile](https://github.com/drupalforge?view_as=member); they are not
published on this site.
